# Section hints

Статические JSON-подсказки для генерации разделов.

Набор `hint_cards` в каждом файле соответствует `SECTION_CONTEXT_FOCUS` этого раздела: планеты × знаки фокуса, при необходимости Асцендент, дома и аспекты/синастрия. Пустой `text_ru` — заготовка для ручного заполнения. Первые карточки с текстом — заполненные примеры.
