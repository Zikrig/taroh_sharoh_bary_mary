# Experimental pipelines

Экспериментальный контур для новых типов генераций. Материалы в этой папке
описывают будущую архитектуру и не меняют текущий production-пайплайн.

## Цель

Разделить процесс на независимые этапы:

1. расчёт астрологической карты;
2. выделение опорных фактов;
3. построение структурированного профиля;
4. написание пользовательского текста;
5. проверка фактов, стиля и безопасности;
6. упаковка результата для Telegram/PDF.

```mermaid
flowchart LR
    Input[Данные рождения] --> Astro[Расчёт карты]
    Astro --> Facts[Отбор фактов]
    Facts --> Profile[Профиль пользователя]
    Profile --> Draft[Черновик отчёта]
    Draft --> QA[Проверка качества]
    QA -->|OK| Render[Telegram или PDF]
    QA -->|Исправить| Draft
```

## Файлы

- `pipeline.md` — схема этапов, режимы free/full и правила повторных попыток.
- `contracts.md` — рекомендуемые контракты входных и промежуточных данных.
- `prompts.md` — роли промптов без привязки к конкретному провайдеру модели.
- `quality_checklist.md` — ручной и автоматический контроль результата.

## Границы эксперимента

- Не изменять `services/ai.py`, пока эксперимент не принят.
- Не передавать модели дату рождения как замену рассчитанной карте.
- Не смешивать бесплатный и платный контекст.
- Не считать текст успешно сгенерированным до прохождения валидации.
- Не сохранять API-ключи и платёжные данные в экспериментальных payloads.

## Рекомендуемый первый эксперимент

Начать с `PERSONALITY_FREE` на одной карте и 3–5 разделах.
Сначала стабилизировать JSON-контракт и валидатор, затем расширять объём и
добавлять `LOVE_FULL`, `MONEY_FULL` и `COMPATIBILITY_FULL`.
